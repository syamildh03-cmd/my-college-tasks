Tentang Proyek

Teknologi yang dipakai di aplikasi ini, dijelaskan sederhana.

Git

Sistem version control yang mencatat setiap perubahan kode (commit), sehingga kita bisa kembali ke versi lama dan bekerja di banyak branch.

GitHub

Layanan online untuk menyimpan repository Git, berkolaborasi lewat Pull Request, dan men-deploy website (GitHub Pages).

npm

Package manager Node.js. Perintah npm install mengunduh library, npm run dev menjalankan script di package.json.

TypeScript

JavaScript dengan tipe data. Di proyek ini: interface Task, tipe Priority dan Status, serta fungsi generics loadData<T>. Kesalahan tipe ketahuan sebelum aplikasi dijalankan.

Vite

Build tool modern: server development yang sangat cepat dan membuat hasil build siap deploy lewat npm run build ke folder dist.

Environment Variables

Konfigurasi di file .env (mis. VITE_APP_NAME), dibaca dengan import.meta.env. Hanya variabel berawalan VITE_ yang masuk ke browser, jadi jangan simpan rahasia di sana.

Dependencies & devDependencies

dependencies dibutuhkan aplikasi saat berjalan. devDependencies hanya untuk proses pengembangan/build. Proyek ini memakai typescript dan vite sebagai devDependencies karena hasil akhirnya hanya HTML, CSS, dan JS biasa.

Semantic Versioning

Format MAJOR.MINOR.PATCH, mis. 1.2.3. MAJOR naik jika ada perubahan yang merusak kompatibilitas, MINOR jika menambah fitur, PATCH jika memperbaiki bug. Tanda ^5.5.4 berarti boleh update MINOR/PATCH, tapi tidak MAJOR.

Compiler, Transpiler, Bundler

Compiler: menerjemahkan kode ke bentuk lain yang lebih rendah levelnya, mis. C ke kode mesin. Transpiler: menerjemahkan antar bahasa selevel; tsc/esbuild mengubah main.ts (TypeScript) menjadi JavaScript yang dipahami browser. Bundler: menggabungkan banyak file; Vite menyatukan main.ts, taskManager.ts, storage.ts, dan style.css menjadi sedikit file di dist/.
