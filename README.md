# My College Tasks

Aplikasi web untuk membantu mahasiswa mengelola dan memantau tugas kuliah dengan mudah.

## Teknologi yang Digunakan

- HTML5
- CSS3
- TypeScript
- Vite
- LocalStorage

## Fitur Utama

- Menambahkan tugas kuliah.
- Mengedit dan menghapus tugas.
- Menandai tugas yang sudah selesai.
- Melihat daftar tugas berdasarkan status.
- Menyimpan data tugas menggunakan LocalStorage.
- Menampilkan dashboard dan statistik tugas.

## Cara Menjalankan Aplikasi

1. Clone repository:
   ```bash
   git clone https://github.com/syamildh03-cmd/my-college-tasks.git
   ```

2. Masuk ke folder proyek:
   ```bash
   cd my-college-tasks
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Jalankan aplikasi:
   ```bash
   npm run dev
   ```

5. Buka alamat lokal yang muncul di terminal.
